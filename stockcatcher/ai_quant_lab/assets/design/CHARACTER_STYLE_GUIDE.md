# 天機 AI Quant Lab 角色美術方向

- 整體：溫暖日式手繪、水彩與色鉛筆紙感、細緻線稿；角色必須保留西施犬扁臉、短吻、大眼與蓬鬆毛流特徵。
- 毛色／毛長變化：奶油白、米白、金棕、咖啡棕、黑白、黑棕；長毛與短毛角色交錯，避免六張外觀完全相同。
- CIO：淺奶油長毛，藏青西裝，負責指揮。
- Quant：黑白中短毛，圓框眼鏡，負責計算。
- Research：金棕長毛，放大鏡／筆記本，負責研究。
- Risk：中深咖啡長毛，紅領結／盾牌，負責風控。
- Execution：黑棕短至中毛，耳機／行情平板，負責模擬執行。
- Auditor：白色蓬鬆長毛，紫色服飾／核對清單，負責驗證。

這份規格是後續製作完整多姿勢素材的標準；現有角色圖為立繪基礎，不能把 CSS 位移誤稱成真正逐格肢體動畫。
